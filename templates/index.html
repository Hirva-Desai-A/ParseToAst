Grammar Used

The parser uses a recursive descent technique.

Statement → IDENTIFIER = Expression ; (semicolon optional)
Expression → Term { (+ | -) Term }
Term → Factor { (* | /) Factor }
Factor → NUMBER | IDENTIFIER | ( Expression ) | - Factor
